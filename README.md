该项目是一个前端动画展示页面，使用了HTML、CSS和JavaScript技术。页面中包含一个折叠面板和一些动画效果。

## 安装

确保您已经安装了Node.js和npm。然后，克隆仓库并安装依赖：

```bash
git clone https://gitee.com/panda-codelab/aniplex_demo
cd aniplex_demo
npm install
```

## 使用

启动开发服务器：

```bash
npm start
```

然后，在浏览器中打开 `http://localhost:8080` 查看页面。
